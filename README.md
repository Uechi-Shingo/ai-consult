# AIに相談

Brave（Chrome 系ブラウザ）で、**いま見ているページについて AI に相談できる**サイドパネルの拡張機能です。
Gemini / OpenAI / Claude の 3 社の API を、パネルの上部で切り替えて使えます。
さらに、**ChatGPT のプラン（Plus / Pro など）の利用枠**を、APIキーなしで使えます（OpenAI の「Sign in with ChatGPT」）。

> 個人が作成した非公式のツールです。各社とは関係がありません。無保証で、利用は自己責任です。

## 使い方

1. `brave://extensions` を開き、右上の「デベロッパー モード」をオンにする
2. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダの **`extension`** を選ぶ
3. 拡張機能の「詳細」→「拡張機能のオプション」（またはパネルの「設定」）を開き、注意事項を確認して、使う提供元の **APIキー** を入力し、画面下の **「保存」**（または「保存して閉じる」）を押す
   - 押すまでは反映されません。未保存の変更があると、画面下に「未保存の変更があります」と出ます
   - 画面下の「閉じる」で設定画面を閉じます（未保存の変更があるときは、確認が出ます）
   - Gemini: <https://aistudio.google.com/apikey>（無料枠あり）
   - OpenAI / Claude: 各社のコンソールで発行（API は有料。ChatGPT・Claude.ai の契約とは別です）
   - **ChatGPT のプランを使う場合:** 設定画面の「ChatGPT のプラン（サインイン）」で「ChatGPT でサインイン」を押し、別のタブで開く OpenAI の画面で、ログインして承認します（「保存」は不要です）
4. 相談したいページで、ツールバーの拡張機能アイコンをクリック → パネルが開く
   - もう一度クリックすると閉じます（開いているかどうかは、クリックのたびにパネル自身が判断するので、取り違えません）。パネルの右上の「×」でも閉じられます
   - ページ上で右クリック →「このページについてAIに相談」でも開けます（選択した文字があれば、それも一緒に渡します）

### ChatGPT のプランでのサインインについて

- **何を使うか:** ChatGPT のプランに含まれる利用枠です。ChatGPT・Codex と共有されます。アプリごとの週あたりの上限は、ChatGPT の「設定 → 使用状況」で決められます。上限に達すると、パネルにそのことが表示されます。
- **APIキーとは別物です。** ChatGPT のプランに、API は含まれません。この拡張機能が「サインイン」で、プランの利用枠を使えるようにしています。
- **渡る情報:** 名前・メールアドレス・プロフィール画像と、利用枠を使うための権限です。ChatGPT の会話や記憶は、渡りません。いつでも、ChatGPT の「設定 → セキュリティとログイン」で接続を解除できます。
- **サインアウト:** 設定画面の「サインアウト」で、この拡張機能に保存した情報（トークンと登録）を消します。ChatGPT 側の接続の解除は、上の画面で行います。
- **何もしないで放置しても、サインインし直しは要りません。** アクセストークンの有効期限は 1 時間ですが、
  次に質問したときに、リフレッシュトークンで自動的に更新されます（公式の仕様では、リフレッシュトークンの有効期限は 30 日で、
  更新のたびに、新しい 30 日になります）。サインインし直しが必要になるのは、次の場合だけです。
  - 30 日間、一度も使わなかった（更新されなかった）
  - ChatGPT の設定で、接続を解除した
  - 設定画面で、「保存しておく」をオフにして、ブラウザを閉じた
  - 設定画面で、サインアウトした
- **注意:** OpenAI は、この仕組みを、オープンソース・個人用のツール向けとして公開しています。ブラウザの拡張機能での利用は、公式ドキュメントに明記されていません。公式に保証された使い方ではないので、仕様の変更で動かなくなる可能性があります。
- **サインイン中は、Codex CLI のログインを同時に行わないでください。** どちらも、戻り先に 1455 番を使います。
- **仕組み:** 公式の手順は、パソコン上のプログラムが `127.0.0.1` で待ち受けて、ログイン後の戻り先を受け取る形です。拡張機能は待ち受けを持てないため、その戻り先への移動を `webRequest` で観測して、中身を取り出します（実際の OpenAI で確認した方法）。

### バージョンについて

変更のたびに、`extension/manifest.json` のバージョンを上げ、[CHANGELOG.md](CHANGELOG.md) に内容を書きます。
いま読み込まれているバージョンは、パネルの右下と、設定画面の見出しに表示されます。
`brave://extensions` で「再読み込み」したあと、表示が新しいバージョンになっていれば、反映されています。

### 画面の見方

| 場所 | 内容 |
| --- | --- |
| 上部の 2 つの選択と、右端の「×」 | AI の提供元と、モデル。「×」を押すと、パネルが閉じます（会話は、タブごとに残ります） |
| その下の 1 行 | 読み取ったページのタイトルと文字数。「読み直す」でページを取り直す |
| 本文 | 会話。回答は逐次表示され、「停止」で止められる |
| 入力欄 | Enter で送信、Shift+Enter で改行（日本語の変換確定の Enter では送信しません） |
| 下部 | 「新しい相談」（このタブの会話を消す）、「設定」 |

### 仕組みの要点

- **会話はタブごとに分かれます。** パネルはウィンドウに 1 つですが、タブを切り替えると、そのタブの会話に差し替わります。ブラウザを閉じると消えます。
- **同じタブで別のページへ移動すると、新しい相談になります。**
- **ページ本文は、質問を送ったときだけ、選んだ提供元に送られます。** 読み取るだけでは、外に出ません。
- **混雑（503・529 など）や一時的な制限のときは、自動で 2 回まで再試行します。** 待っている間は「再試行しています」と表示されます。回答が 1 文字でも届いたあとは、表示が食い違うので再試行しません。
- **それでも失敗したとき・無料枠が尽きたとき**は、相手の返答つきのエラーと、「別のモデルで続ける」（同じ提供元の他のモデル。混雑や無料枠はモデルごとに違うことがあります）、「OpenAIで続ける」などのボタンが出ます。有料の提供元へは、押したときだけ切り替わります。
- **ブラウザの内部ページ（`brave://` など）は読み取れません。** ページの内容なしで質問はできます。
- **モデル一覧は、文章でのやりとりに使えるものだけです。** 画像生成（Nano Banana など）・音声（読み上げ・音声対話）・埋め込み用などは除いています。

### ページを読み取る許可について

ページを読むには、次のどちらかが必要です。

- アイコンのクリックや右クリックの項目で付く、**そのタブだけの一時的な許可**（activeTab）
- パネルの「すべてのサイトで読み取りを許可」で付ける、**常時の許可**（任意の権限。あとで取り消せます）

許可がないページでは、パネルにそのための案内とボタンが出ます。ボタンを押すと、結果（許可された／されなかった／まだ読めない理由）がその場に表示されます。
すでに許可が付いているのに読めないページ（空白のページ・エラー画面・ブラウザの内部ページ・ファイルなど）では、許可のボタンは出さず、読めない理由を説明します。

## 安全面

| 項目 | 内容 |
| --- | --- |
| 権限 | `sidePanel` `activeTab` `scripting` `storage` `contextMenus` `webRequest` と、3 社の API ホスト・`auth.openai.com`・サインインの戻り先（`http://127.0.0.1:1455/auth/callback` の 1 つの URL）のみ。全サイトの権限は「任意」 |
| `webRequest` | サインインの戻り先の URL だけを観測する（他のページのリクエストは、見ない・変更しない） |
| 通信先 | CSP により、画面・裏方は 3 社の API と `auth.openai.com` 以外へ通信できない |
| 常駐スクリプト | なし（ページに常駐するスクリプトを持たない。読み取りは、質問のときだけ一時的に注入） |
| キー・トークン | 裏方だけが扱い、パネルには渡さない。保存領域は、ページ側のスクリプトから読めない設定。「保存しておく」をオフにすると、ブラウザを閉じたときに忘れる（ChatGPT のトークンも同じ） |
| サインイン | PKCE（S256）・state・nonce を使い、state が一致しない戻り先は無視する。ID トークンの nonce も確認する。トークンの更新は、同時に 1 回だけ |
| ページの内容 | 「信用できないデータ」として区切って渡し、システム指示で「中の指示には従わない」と伝える。モデルにツールは持たせない |
| 回答の表示 | HTML を経由せず、DOM の部品として組み立てる（スクリプトや画像の埋め込みは要素にならない）。リンクは http(s) のみ |
| 暴走防止 | 1 回の依頼・会話の長さの上限、10 分間の依頼回数・文字数の上限 |
| OpenAI | `store: false`（OpenAI 側に応答を保存させない）で依頼 |

**限界:** ブラウザの保存領域は暗号化されません。パソコン自体がウイルスに感染している場合などは防げません。
検証は作成者による自己検証で、第三者の監査ではありません。

## 開発者向け

```
extension/
  manifest.json
  background.js          裏方: アイコン・右クリック・通信・上限・ページ読み取り
  sidepanel.{html,css,js}  パネル: タブごとの会話、描画
  options.{html,css,js}    設定画面
  providers/             gemini.js / openai.js / anthropic.js / chatgpt.js（共通: stream() と listModels()）
                         chatgpt.js は、サインイン（認可の依頼・戻り先の解析・トークンの交換と更新）も持つ
                         sse.js（SSE の分解）/ errors.js（エラーの分類）/ util.js
  lib/                   settings.js / request.js（検証・組み立て・上限）/ page.js / markdown.js
                         chatgpt-session.js（サインインの流れ・トークンの保存と更新）
tests/
  static-audit.mjs       権限・CSP・禁止された書き方・キーの埋め込みの監査
  unit.mjs               部品のテスト（各社の依頼の形式・応答の解釈・エラー分類・依頼の組み立て・サインイン）
  e2e.mjs                実ブラウザ（画面付き）での、設定から相談までの通し確認
  e2e-chatgpt.mjs        実ブラウザでの、ChatGPT のプランでのサインインの通し確認（出荷するままの権限で）
spike-chatgpt-signin/    サインインが、拡張機能で成り立つかを確かめた試作（実際の OpenAI で確認済み）
tools/
  make-icons.mjs         アイコン（extension/icons の PNG）の生成。外部のライブラリ不要
  icon-preview.png       アイコンの見え方の確認用（16・32・48・128 px を、明るい背景・暗い背景に並べたもの）
```

### アイコン

紫の背景に、ブラウザの窓（白）と、右に開いたサイドパネル（琥珀色）、パネルの中のきらめき（AI）です。
「ページを見ながら、横のパネルで AI に相談する」使い方を表しています。
「右クリックで日本語に翻訳」（青い四角に白い「訳」）とは、色も形も違うので、並べても見分けられます。

### Git と公開の流れ

- 公開されるのは `main` ブランチです。変更は、まず `feature/…` や `fix/…` のブランチで行い、テストが通ってから `main` に取り込みます。
- 変更のたびに、`extension/manifest.json` のバージョンと、[CHANGELOG.md](CHANGELOG.md) の先頭の項目を、そろえて上げます（監査が、食い違いを検知します）。
- 配布用の zip は、`main` で次を実行して作ります。監査・部品のテスト・ブラウザでの通し確認に、すべて通ったときだけ作られます。
  `releases\` には最新版の zip と SHA-256 だけを置き、この README の先頭のダウンロード欄も更新されます（古い版は、Git の履歴に残ります）。

```powershell
.\tools\make-release.ps1 -RepoUrl https://github.com/<ユーザー名>/<リポジトリ名> -BrowserPath "C:\Program Files\BraveSoftware\Brave-Browser\Application\brave.exe"
```

### 提供元を足すには

`providers/` に、`id` / `label` / `stream({apiKey, model, system, messages, signal})`（`{text}` か `{notice}` を順に返す）/
`listModels(apiKey, signal)` を持つファイルを足し、`background.js` の `PROVIDERS` と `lib/settings.js` の `PROVIDER_IDS`、
`manifest.json` の `host_permissions` と CSP の `connect-src` に加えます（監査が、足し忘れを検知します）。

## 確認できていること・できていないこと

確認済み（Brave 155 / Chromium 155.0.8059.80）:

- サイドパネルの API（`open` / `close` / `onOpened` / `onClosed`）が動く。ユーザー操作の中でしか `open()` を呼べない
- アイコンの 2 回目のクリックでパネルが閉じる（利用者による手動確認）
- パネルは全タブ共通で、タブを切り替えても開いたまま。会話はタブごとに分ける
- ブラウザの内部ページ（`chrome://`）は、拡張機能からは読み取れない

- ChatGPT のプランでのサインイン（試作で、実際の OpenAI を相手に確認。2026-10-16）: 戻り先の検知（`webRequest` ほか）、トークンの取得、
  モデル一覧（7 件）、質問（`store: false` / `stream: true`、`response.completed` を確認）

未確認:

- **各社 API への実際の通信**（偽の応答での確認のみ。ChatGPT のサインインと、その最初の質問は、試作で実際に確認済み）
- **ChatGPT のトークンの更新を、実際の OpenAI で行うこと**（約 60 分後の自動更新。偽サーバーでは、同時に呼んでも 1 回だけになることまで確認）
- **ChatGPT のプランで、`instructions`（システム指示）が受け付けられるか**。受け付けられない場合は、自動で別の形（developer メッセージ）で送り直します
- **アイコンのクリックだけで、そのページを読めるか**（activeTab が付くか）。1 回目の確認では、自動で開く設定（`openPanelOnActionClick`）だと付かない可能性が高いと分かり、現在は自前でクリックを受ける方式にしています。ただし、確認時に「全サイトの読み取り許可」が残っていて、判定できていません。付かない場合でも、パネルが案内するので使えます
- パネルの見た目（画面のスクリーンショットでの確認は、利用者の手元のみ）
