最初にお読みください

  • 質問を送ると、表示中のページの本文が、選んだ提供元（Google / OpenAI / Anthropic）に送られます。メール・社内文書・個人情報のあるページでは使わないでください。
  • Gemini の無料枠では、送った内容が提供元の製品改善に使われ、人が確認することがあります。EEA・スイス・英国では、無料枠が使えない場合があります（Google の「Gemini API 追加利用規約」をご確認ください）。
  • OpenAI・Claude の API は有料（従量課金）です。ChatGPT や Claude.ai の契約とは別に、API キーと残高が必要です。
  • APIキーは、このブラウザの拡張機能の保存領域にだけ保存し、各提供元への通信以外には使いません。ただし暗号化はされません。共用のパソコンでは、下の「保存しておく」をオフにしてください。
  • 個人が作成した非公式のツールで、各提供元とは関係がありません。無保証で、利用は自己責任です。
